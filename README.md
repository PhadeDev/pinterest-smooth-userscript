# Pinterest Smooth Userscript

Makes Pinterest less irritating in desktop browsers with Violentmonkey or Tampermonkey.

## Install

[Install Pinterest Smooth](https://raw.githubusercontent.com/PhadeDev/pinterest-smooth-userscript/main/pinterest-smooth.user.js)

## Features

- Blocks Pinterest video autoplay, including hover and scroll-triggered playback.
- Adds a visible video badge and click-to-play overlay on video cards.
- Adds local play, mute, and volume controls for videos.
- Hides promoted, sponsored, and ad-like cards.
- Uses direct pin navigation to avoid some of Pinterest's laggy SPA routing.
- Reduces animation noise and exposes a small floating control panel.

## Notes

Pinterest changes its generated markup often. If something slips through, open an issue with the page type and what happened.
